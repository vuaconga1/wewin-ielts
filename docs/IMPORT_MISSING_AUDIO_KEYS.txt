NHẬT KÝ ĐỀ THIẾU AUDIO / ĐÁP ÁN (KEYS) KHI IMPORT
====================================================
Quy ước: mỗi lần import bộ đề mới, ghi thêm một mục ở cuối file.
  - THIẾU AUDIO      : nguồn không có file nghe -> bỏ phần Listening (hoặc ghi cách xử lý)
  - THIẾU KEYS       : nguồn không có đáp án -> ghi rõ: tự tạo (từ nguồn nào) / bỏ đề
  - THIẾU CÂU        : đề gốc thiếu câu hỏi
  - KEY ĐÃ SỬA       : đáp án gốc sai, đã chỉnh
Trạng thái import mặc định: DRAFT.
